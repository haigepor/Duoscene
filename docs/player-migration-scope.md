## 目标与范围

直接复用 Playra 当前固定 media-kit 分支、播放控制与已有独立控件，保留播放器交互与布局。
接通 Duoscene 房间详情入口，支持 MP4/HLS、暂停/播放/seek/倍速、横竖屏/锁定、手势、比例、音轨/字幕、
截图、缓存/硬解/渲染/超分设置及播放信息。平台能力按实际 Android/iOS 支持提供，不伪造成功。
与房间同步冲突的自动播放/续播通过明确入口管理；移植代码保留来源和变更记录。

允许修改 apps/mobile/**、根 third_party/playra-player 许可记录、相关 docs/README、播放器测试脚本。
第二片允许 api realtime/media/checkpoint、对应契约/测试与移动端同步入口，但须在原生播放验收后开始。
保留 auth/rooms 已验证的 HTTP/数据库语义；不迁入片源搜索、私有 SDK、个人收藏/历史库、下载器或旧 Syncplay 服务。
不修改 Playra 来源项目、全局 Codex 控制配置、WSL/Docker 或现有账户。

## 验收与回退

- 原生测试使用受控本地 MP4/HLS、实际 HTTP 请求头与真播放器，不以 mock 代替首帧、seek 和销毁验收。
- 单元/widget 覆盖切换代际、拖动取消、暂停状态、窄屏/大字号和控件入口；保留登录房间回归。
- 双人同步须另有权威状态、权限/版本/去重/重连测试与双客户端证据，不能用单机 UI 代替。
- 当前无 Git；修改前文件与哈希保存在 .local/backup/2026-10-19-player/，只按清单逐文件回退。
- 原生平台不支持或无法在 Windows 验证的能力明确列出，不能算作已通过。
