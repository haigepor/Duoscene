# 认证页间距与胶片装饰调整

## 设计对照与结果

移除注册、找回密码表单主按钮下方的恢复码说明；保留标题下的简短介绍，以及提交成功后的恢复码、复制操作与安全保存确认。认证、校验和恢复码约束没有变化。

原布局将 136dp 的介绍区、24dp 下间距、16dp 列表顶部留白叠在一起，造成标题与首字段之间的空白偏大。本次统一调整：

| 项目 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 列表顶部留白 | 16dp | 8dp |
| 介绍区最小高度 | 136dp | 112dp |
| 介绍区底部间距 | 24dp | 16dp |
| 常规装饰插图尺寸 | 112dp | 96dp |
| 注册/找回字段组下间距 | 16dp | 12dp |
| 登录两字段之间间距 | 24dp | 16dp |
| 忘记密码与登录按钮间距 | 24dp | 12dp |

首字段上移 40dp，注册与找回密码主按钮上移 56dp。主按钮与输入控件仍保持至少 48dp 高度，字体、配色、圆角均复用现有 token，没有通过缩小触达区域压缩页面。320dp/200% 字体与键盘场景保持滚动可达。

设计稿中的胶片是放大后延伸至页面边缘的背景装饰。原实现把完整素材缩小居中显示，显得像独立摆件。本次继续使用用户最后选定的素材，显示高度从 144dp 调整为 192dp，左右各延伸 48dp，底部延伸 16dp，由页面边界裁切，并在既有主题透明度基础上乘以 0.65。没有重新生成、修改素材文件，也没有增加实时模糊或全屏滤镜。小屏、键盘与大字体下继续隐藏胶片。

## 绘制检查

额外核查了首字段装饰。虽然查看截图时一度怀疑有漏绘，但逐像素比对显示首字段背景、图标和标签区域在临时绘制隔离前后完全一致，未证实存在该缺陷，因此没有保留 RepaintBoundary 试验。截图采样与注册/找回交替进入记录位于 `.local/backup/auth-spacing-20261021/paint-verification.json`；不改变全局导航或输入状态。
