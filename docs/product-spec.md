# 需求摘要与本轮验收

产品面向两个私有账户，在不同国家/网络下同步观看手机端视频并语音聊天。
技术主栈已经确定，不在骨架阶段重新选型。

## 首版功能边界（待实现）

1. 管理员安全创建两个私有账户；登录、refresh 轮换、注销，关闭公开注册。
2. 私密房间、限时一次邀请、持久两席位、在线状态、主动退出/移除与同账号设备接管。
3. 影片/集数与播放列表，双方可控制播放/暂停/seek/倍速/结束。
4. 双方在线且准备好才共同播放；缓冲共同冻结，15 秒等待初值；手动暂停清除继续意图。
5. epoch/revision/generation 隔离、校时、冲突与有界去重、重连和服务重启后暂停恢复。
6. Provider 独立签名地址、相同内容时间线校验和有界过期刷新。
7. P2P/TURN 双人语音、静音与音量分离；拒绝麦克风仍允许观看。
8. 有限聊天历史、观看进度/最近记录、日志与探针。

视频不经过 API 转发，不做转码、存储、电影 CDN、视频通话、录制或屏幕共享。
首版单机单 API，无公开社区、付费、多租户、Redis、微服务或 Kubernetes。
