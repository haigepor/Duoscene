# 晴空主题与账户流程交付

日期：2026-10-20。适用：本地 Flutter Android 调试环境。

## 使用

- 登录页右上角太阳图标，或「我的 → 外观」：选择晴空 / 森林；晴空可选浅色、深色、跟随系统。
- 新安装默认晴空并跟随系统；发现旧版本机片库数据时保留森林。选择写入设备本地偏好，不依赖账户。
- 登录页提供注册、忘记密码。开放注册后显示恢复码；保存并确认后返回登录。恢复码只能用于一次密码恢复，成功后生成新的恢复码，并撤销旧登录会话。
- 旧管理员创建的账户没有恢复码，仍需管理员协助；不会为它们静默生成或公开恢复码。
- 首页「一起看」进入真实房间；短剧页的聊天入口在真实账户下进入同看房间，避免出现无法发送的预览输入框。

## 实现范围

| 范围 | 修改与影响 |
| --- | --- |
| 主题基础 | `DSPalette` ThemeExtension 管理背景、表面、正文、主操作、气泡、状态、错误及媒体角色。`DS` 仅保留尺寸、字级和动效，不再包含固定森林颜色 |
| 主题生命周期 | `ThemePreferences` 串行持久化、升级默认值、系统明暗；更换外观保留 Navigator、输入、媒体实例与房间连接 |
| 全页面 | 18 个预览页面及真实认证、房间列表/表单/详情、播放器、实时聊天统一语义色；森林资源继续保留；晴空使用实色工具背景 |
| 组件 | 正文14、辅助12、页面标题18；输入/按钮48；SVG颜色跟随角色；无操作的菜单不显示假箭头；系统状态栏随主题适配 |
| 动效 | 无背景 Tab 下划线、内容小位移淡入、状态缓存、按滚动距离渐变吸顶；减少动画设置保留；轮播可暂停，触摸后持续暂停，顶部控制具备暗底对比 |
| 首页/搜索 | 紧凑续看直达播放器；一起看入口；轮播与内容保持间距；分类与关键词独立；结果改为64×90海报紧凑整行 |
| 记录/收藏 | 固定批量操作底栏；切换筛选清除旧选择；失败保留未完成选择，避免重试误加回已删除收藏 |
| 播放器 | 沿用 Playra / media_kit 内核、全屏、手势、截图、播放列表和本地媒体；媒体覆盖文字固定白色；正常内容跟随主题 |
| 双人观看 | 键盘展开时收缩视频而不卸载播放器；历史阅读不被新消息拉到底部；新消息提示；加载旧消息按可见消息位置校准 |
| 账户安全 | 新增 register/recover 接口、严格字段验证、每路由每IP每分钟5次限制、恢复码只存 SHA-256、事务单次消费、密码 scrypt、旧会话撤销 |

设计细节以 [设计审查](ui-audit-theme-direction-2026-10-20.md) 为方向；本报告记录实际交付。片库仍为有明确标识的设计片目，没有新增在线影视来源。观看记录保留「最近观看」分组，现有数据没有观看日期，未伪造日期分组。房间管理页仍保留显式「打开播放器」，接收邀请页则直接进入同看。

## 验证方法与证据

以下均使用当前仓库实现；预览与真实功能证据分别说明。

- `flutter analyze`：静态检查。
- `flutter test --reporter expanded`：原有回归，加主题持久化/状态保留、注册恢复码确认、聊天跟随与历史锚点。
- 外观矩阵：18页 × 3主题 × 320dp/200%、390dp/200%、430dp/160%，共162次页面渲染；另有320dp/160%的既有检查。
- `node apps/mobile/tool/ui-native.mjs`：雷电原生54张主题页面、24种预览异常/交互状态、4项真实导航/滚动/播放器组合，共82张截图，位于 `.local/screenshots/ui/`。预览私聊、虚构片目、示例邀请不等同真实同步。
- `npm run typecheck`、`npm test`：API类型、HTTP边界、限流、序列化、合约及既有业务测试。
- `DUOSCENE_TEST_DATABASE=duoscene_test_local` 下运行既有 MySQL 集成和 `apps/api/test/account-recovery.integration.ts`：注册、重复账户、错误恢复码、并发单次消费、轮换恢复码、旧access/refresh/WS身份撤销、禁用账户。
- `scripts/test-realtime-pair.mjs`：两台雷电通过真实UI注册、重设密码、登录、创建/邀请/加入；真实 MySQL、WebSocket、MP4/HLS 解码、暂停/拖动/倍速、双向私聊、WebRTC RTP收发、静音和重连。主题切换检查媒体对象与连接保持一致。
- 双端机器报告：`.local/realtime-pair-result.json`；截图：`.local/screenshots/realtime/`。测试账户和房间按本次随机后缀清理，不使用日常账户。

## 迁移与回退

新增迁移 `apps/api/migrations/0009_account_recovery.sql`，已用于本地开发库和隔离测试库。只增加可空恢复码哈希字段，不改旧迁移。

源码备份：`.local/backup/2026-10-20-sky-theme/`。逐文件清单、当前哈希和新增/修改标记见同目录交付清单 `sky-theme-change-manifest-2026-10-20.json`。回退时只替换清单中的已修改源码，移除对应新增源码；不要整目录覆盖之后的新工作。数据库列可保留，旧代码不会使用；切勿删除整个数据库来回退UI。

未改 AGENTS、Skills、全局配置、依赖版本、Playra内核或同步协议。测试脚本的备份依据本轮精确修改还原。

## 边界

- 本轮验证为本地调试APK与雷电双实例，不代表外网 NAT、生产部署或真机性能认证。
- 语音验证包含两端 RTP 字节收发和静音轨道状态，不等同真实用户主观音质测试。
- 调试模拟器日志存在既有渲染器/Impeller提示；未据此声称60fps性能达标。
- 邮箱、短信、客服提交、自动更新、真实片源搜索不在当前后端能力内，界面不会伪装已接通。
