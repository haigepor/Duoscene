## Why

用户在实际设备发现封面缺失、分类筛选与同源参考 App 的数据呈现不一致，且短剧沿用长视频播放器的外壳造成体验问题。用户要求保持 Duoscene 既有页面风格，短剧顶部只留搜索图标并优化底部信息，参考设备中的追剧喵数据行为，调研 GitHub 开源播放方案。

## What Changes

- 通过真实 SDK 数据和有限 HTTP 实测定位封面失败，建立安全、可测试的图片策略和错误恢复，不以其他影片图片冒充成功。
- 对照参考 App 的首页、分类、搜索和播放字段；只对验证成功的远端筛选建立契约，未支持能力明确降级，分页和空结果不得误导。
- 保留原页面外壳，改进元数据归一化和渲染；短剧按明确授权简化顶部、修正底部布局与播放器安全区。
- 调研 media-kit、Better Player Plus、Chewie 和 AndroidX Media3 等官方仓库，区分 UI/流控制和解码内核问题，分阶段选择最小风险实现。
- 补充回归、样式边界、设备交互、实际播放和 APK 验证。后端只通讯的边界不变。

## Capabilities

### Modified Capabilities
- `frontend-media-provider`: 图片、筛选、数据渲染与短剧播放体验。

## Impact

仅限移动端片库、短剧与必要的窄播放呈现接口、测试和文档。不会重设计其他页面，不迁移账号，不改后端或协议加解密。播放器依赖替换必须有兼容性、许可、维护状态和设备验证证据，不能只凭仓库热度决定。
