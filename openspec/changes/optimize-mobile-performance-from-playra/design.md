## Slices

1. 构建模式与包实物：Debug/单 ABI/Release-like 体积分解，确认大项、未用资产、重复库和结构空洞；不得删除 WebRTC 或原生解码能力换数字。
2. 内容链路：首屏优先、按需分类、列表与详情区分、同键请求合并、短期缓存；筛选键包含类别/参数/页码，失败和旧请求不得污染新数据。
3. 图片与滑动：尺寸感知解码、压缩字节缓存、有限缓存预算、坏图失效和手动重试；不得丢失本轮已验证的请求头策略。
4. 页面与状态：缓存 Element 与输入/滚动、可见性停工、局部进度通知；先测 blur/纹理合成与 UI build，再决定实现，不擅自改原视觉。
5. 播放协调：详情/目录复用、代次取消、prepared freshness、媒体稳定身份、线路样本排序、真实首帧验收；不机械移植旧协议、全线路扫描或 1.5 GiB 缓冲上限。

## Acceptance

每片给出基线与修改后相同操作/设备/构建模式的数据。FrameTiming 原始数据保留，不把单阶段超预算当实际丢帧率，不把 Activity TotalTime 当推荐数据就绪时间。不清账号数据，原视觉基准与 LAN/收藏/历史/选集/同看回归必须通过。
