## ADDED Requirements

### Requirement: Measured optimization
The application SHALL compare performance on the same physical device and comparable build modes. Evidence SHALL separate startup display, data readiness, UI build, raster, parsing, buffering and first-frame time.

#### Scenario: A debug package stutters
- **WHEN** debug performance is inspected
- **THEN** it is labelled diagnostic and not presented as final release smoothness or as proof of a decoder defect

### Requirement: Preserve product contracts
Optimization SHALL preserve approved original visuals, active playback ownership, stable media identity, LAN development access and account data. Playra reuse SHALL remain licence-compliant and avoid copying incompatible protocols or app-global state.

#### Scenario: Reuse a prepared media result
- **WHEN** provider, work, line, episode, quality or expiry differs
- **THEN** the result is not reused and a fresh, cancellable resolution is performed

### Requirement: Evidence-based package reduction
Package reports SHALL inspect delivered archive contents and distinguish compressed bytes, installed data, runtime memory and store download size. Required codecs, communication, licence notices and used assets SHALL NOT be removed without explicit scope approval.
