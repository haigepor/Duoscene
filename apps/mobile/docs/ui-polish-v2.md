# Duoscene 全页面精修与动效设计

日期：2026-10-20。复杂度 L；以当前 18 张 Android 截图、原稿 PNG、用户提供的两张播放器截图及 Playra 当前源码为证据。保留原稿森林黑绿、米白、薄荷色与四个主 Tab；本轮按用户授权调整播放器信息架构和过大的功能页尺寸，不宣称像素级 1:1。

## 结论与范围

问题不是整体缩放比例，而是各层级混用了 20–30dp 标题、固定大头像、重复信息和两套播放器主题。直接缩小所有控件会同时损害点击区域与大字体支持。采用语义 token、明确层级、保留原生文字缩放，并收敛导航入口。

允许修改：mobile/design、app/theme、catalog、experience、auth/login 的展示层；现有播放器 page/surface/settings 的展示组合；对应测试、素材与文档。保持播放器 session/core、vendor、原生依赖、数据库和 API 协议不变。没有修改 Playra 项目或原始设计文件。当前工作目录没有 Git，使用本轮独立目录备份和 SHA256 文件清单比较。

## Playra 参考与差异

参考 `D:/project/Playra/lib/presentation/shared/mobile_tab_view.dart` 的 280ms、easeOutCubic、已访问页保留、反向切换接续、TickerMode/ExcludeFocus/ExcludeSemantics/IgnorePointer。Duoscene 的 `MotionTabs` 保留 Element 而不缓存旧 Widget 闭包，确保 library 更新和 short.active 不会停留在过期值。没有加横向拖动识别，避免与短剧、进度拖动竞争。

主题取法参考 Playra modern home/settings scope：集中 ThemeData、语义颜色、显式字号与可见尺寸、标准触控密度。没有复制其紫色主题或引入整个应用路由。

减少动画时，Tab 和隐式过渡使用零时长；页面进入不位移不淡入。滚动头部直接跟随位置，没有惯性延迟。播放器控制层只改变 opacity 与命中状态，不更换 Texture/播放会话。

## 播放器交互边界

- 影片入口与通用文件入口共享空态、色彩、快捷操作；影片页保留交流/简介，通用入口聚焦播放列表。
- 网络地址、本地视频、倍速、画幅、字幕、音轨、解码、截图、截图查看、休眠、后台和 PIP 仍使用原控制器。
- 横屏保留完整媒体顶部栏；竖屏使用页面顶部栏，消除重复返回与标题。
- 私聊仍是明确标记的预览，真实同步与语音服务没有在本轮实现；不把成员身份当作在线或已同步。
- 真实播放记录、邀请 token、鉴权 header、一次性邀请期限没有修改。
