# Flutter 原稿实施

视觉基准：桌面交付目录中的 18 张 imagegen 原始 PNG，已逐张查看。V3 仅复用 Lucide 图标与状态语义，不复用页面样式、几何头像或主题。

| 能力 | 已存在 / 本次复用 | 本次补齐 | 需要预览适配 |
| --- | --- | --- | --- |
| 私有账户 | Session、安全存储、真实登录退出 | 原稿登录与账户页 | 独立调试预览，不创建凭据 |
| 房间邀请 | RoomRepository、15 分钟一次性邀请、加入 | 入口与产品说明 | 接收前无公开邀请查询，不能伪造发送者 |
| 播放 | Playra 全套内核、控制、生命周期 | 产品播放页组合接口 | 原稿图片不是片源，缺失时选择用户媒体 |
| 目录收藏记录 | 暂无后端 | 原稿目录、搜索、账户隔离本机存储 | 目录明确为设计预览 |
| 聊天语音同步 | 暂无服务 | 页面、状态、确认交互 | 调试预览模型，不声称联网或已读 |

实施顺序：基础主题和组件 → 四标签 → 搜索详情播放与抽屉 → 邀请及辅助页 → 状态与原生验证。

范围：apps/mobile/lib、assets/design、pubspec、test、integration_test、docs。必要的 Android 只读应用版本查询允许最小扩展；不改变播放器原生参数、minSdk、打包策略、后端、数据库、third_party 或 Playra 源仓库。

回滚：现有文件基线备份在 `.local/backup/2026-10-19-flutter-ui/`，manifest.json 记录 SHA256；新增文件由交付清单记录。没有 Git，因此只按文件恢复，不能覆盖其他人后续变更。

验收：18 个页面入口、21 个状态、真实登录房间回归、Playra MP4/HLS 回归、分析与组件测试、Android 雷电模拟器截图、UTF-8 和变更范围审计。
